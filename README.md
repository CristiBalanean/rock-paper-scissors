# ✊✋✌️ Rock Paper Scissors

A classic Rock Paper Scissors game against the computer, built with vanilla JavaScript. Pick your move, track your score, and try to outsmart the randomizer.

🔗 **Live Demo:** [cristibalanean.github.io/rock-paper-scissors](https://cristibalanean.github.io/rock-paper-scissors/)

---

## Features

- Play against a randomized computer opponent
- Live score tracking for wins, losses, and draws
- Reset button to start a fresh session
- Visual feedback with emoji-style icons for each move
- Responsive layout for desktop and mobile

---

## Tech Stack

- **HTML** — Page structure and layout
- **CSS** — Styling and responsive design
- **JavaScript** — Game logic, randomized opponent, score state management, DOM updates

---

## Project Structure

```
├── index.html       # Game markup
├── scripts/         # Game logic and event handling
├── styles/          # CSS styling
├── images/          # Rock, paper, scissors emoji assets
└── README.md
```

---

## Getting Started

```bash
git clone https://github.com/CristiBalanean/rock-paper-scissors.git
cd rock-paper-scissors
```

Open `index.html` in your browser — no build step needed.
